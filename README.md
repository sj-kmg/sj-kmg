# 신정개발(주) 경영지원 대시보드

엑셀 파일을 데이터 원본으로 사용하는 경영지원 대시보드 웹 서비스입니다.

## 🔒 보안 원칙

**데이터 엑셀 파일은 이 저장소에 절대 올라가지 않습니다.**

- `.gitignore`가 모든 스프레드시트 파일(`*.xlsx`, `*.xls`, `*.csv` 등)과 `data/` 폴더의 커밋을 차단합니다
- 이 저장소에는 **대시보드 웹 앱 소스코드만** 존재합니다
- 데이터는 사용자가 대시보드 화면에서 **자신의 PC에 있는 엑셀 파일을 직접 열어** 표시합니다
- 파일은 **브라우저 안에서만 해석(SheetJS)** 되며, 서버나 외부로 전송되지 않습니다
- 새로고침 후에도 보이도록 브라우저 저장소(localStorage)에만 캐시되며, 화면의 "데이터 지우기" 버튼으로 즉시 삭제할 수 있습니다

## 사용 방법

1. 배포된 대시보드 접속 (Vercel)
2. "엑셀 파일 열기"를 눌러 PC의 데이터 파일(`sj-data.xlsx`) 선택 — 또는 드래그&드롭
3. 개요·프로젝트·매출·매입·자금·인사 탭에서 현황 확인
4. 엑셀에서 데이터 수정 후 저장했다면, 대시보드에서 파일만 다시 열면 반영 (커밋/업로드 불필요)

## 데이터 파일 규격 (`sj-data.xlsx` — 로컬 보관)

| 시트 | 내용 |
|---|---|
| 사용안내 | 입력 규칙, 코드 규칙 |
| 기준정보 | 회사 정보, 부가세율·4대보험 요율, 드롭다운 코드 목록 |
| 거래처 | 발주처·협력사·자재업체 마스터 |
| 프로젝트 | 수주 현장 마스터 (계약금액, 진행상태, 진행률) |
| 매출 | 기성/준공 청구·수금 (미수금 자동 계산) |
| 매입 | 자재비·외주비·노무비 등 (미지급금 자동 계산) |
| 자금일보 | 계좌 입출금·잔액 누계 |
| 인사명부 / 급여대장 | 임직원 정보, 월별 급여 |
| 월별요약 | 엑셀용 자동 집계 (웹은 원본 시트에서 자체 계산) |

> ⚠️ 시트 이름과 1행 헤더는 변경 금지 — 대시보드가 이 이름으로 데이터를 찾습니다.

## 개발

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # 프로덕션 빌드
```

기술 스택: Next.js (App Router) · TypeScript · SheetJS(xlsx) · Recharts
