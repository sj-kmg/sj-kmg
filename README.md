# 신정개발(주) 경영지원 대시보드

엑셀 파일을 데이터 원본으로 사용하는 경영지원 대시보드 웹 서비스입니다.

## 구조

```
data/sj-data.xlsx   ← 데이터 원본 (경영지원 담당자가 직접 입력/관리)
(웹 앱 소스는 추후 추가 예정)
```

## 데이터 파일 (`data/sj-data.xlsx`)

| 시트 | 내용 |
|---|---|
| 사용안내 | 입력 규칙, 코드 규칙 (파일 열면 첫 시트) |
| 기준정보 | 회사 정보, 부가세율·4대보험 요율, 드롭다운 코드 목록 |
| 거래처 | 발주처·협력사·자재업체 마스터 |
| 프로젝트 | 수주 현장 마스터 (계약금액, 진행상태, 진행률) |
| 매출 | 기성/준공 청구·수금 (미수금 자동 계산) |
| 매입 | 자재비·외주비·노무비 등 (미지급금 자동 계산) |
| 자금일보 | 계좌 입출금·잔액 누계 |
| 인사명부 / 급여대장 | 임직원 정보, 월별 급여 |
| 월별요약 | 자동 집계 (웹에서는 자체 계산) |

## 데이터 갱신 방법

1. `data/sj-data.xlsx`를 Excel에서 열어 입력 후 **저장** (수식 재계산 필수 — 웹이 수식 캐시값을 읽음)
2. 이 저장소에 커밋 & 푸시
3. 대시보드가 자동으로 최신 데이터 반영

> ⚠️ 시트 이름과 1행 헤더는 변경 금지 — 웹 서비스가 이 이름으로 데이터를 찾습니다.
